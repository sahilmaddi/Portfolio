# Sahil Maddi | Portfolio

Personal portfolio for Sahil Maddi, Java Full Stack Developer.

Built with React, Vite and Tailwind CSS. Deployed on Vercel.

## Run locally

```bash
npm install
npm run dev
```

## Update content

All text, projects, experience and certifications live in `src/data.js`.
Static files (photo, favicon, resume PDF) live in `public/`.
